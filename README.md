# Introduccion-a-interfaces-graficas-Grupo-B

## Descripción

Este programa implementa una calculadora básica desarrollada en Python utilizando módulos y funciones.

La calculadora permite realizar las cuatro operaciones matemáticas básicas:

- Suma (+)
- Resta (-)
- Multiplicación (×)
- División (/)

El proyecto utiliza un módulo llamado `Operaciones.py`, donde se encuentra la lógica matemática, y un archivo `main.py`, encargado de solicitar los datos al usuario y ejecutar la operación seleccionada.

## Estructura del Proyecto

- `Operaciones.py`: contiene las funciones matemáticas.
- `main.py`: contiene la interacción con el usuario y utiliza las funciones del módulo.
- `README.md`: documenta el proyecto.

## Funcionalidades

- Sumar dos números.
- Restar dos números.
- Multiplicar dos números.
- Dividir dos números.
- Validar la división entre cero.
- Seleccionar la operación mediante un menú.
- Mostrar el resultado al usuario.

## Uso

Ejecutar el programa con:

```bash
python main.py
```
